# Edge local HTTP API reference

**Scope:** FastAPI routes under `src/api/` as inspected 2026-11-23. The local OpenAPI schema (`/openapi.json`) is the complete machine-readable schema. This page groups the stable operator/developer entry points; it is not an exhaustive autogenerated endpoint listing.

## Base and events

Default local address: `http://127.0.0.1:8000`.

| Endpoint | Method | Purpose |
| --- | --- | --- |
| `/health` | GET | Local health |
| `/api/digiflot/state` | GET | Current run, stage and instrument state |
| `/api/digiflot/stream` | GET | Server-Sent Events of state changes |
| `/api/digiflot/system/health` | GET | System and device health |
| `/api/server/status` | GET | Cached catalog, outbox and connection health |
| `/api/server/sync` | POST | Queue a sync attempt (202) |

An SSE stream is not a command channel; submit actions through HTTP POST/PUT/PATCH as defined below.

## Experiment and stage operations

| Endpoint | Method | Purpose |
| --- | --- | --- |
| `/api/digiflot/experiments/{storage_id}/start` | POST | Select local cached experiment and prepare execution |
| `/api/digiflot/calibration/cell/select` | POST | Select effective flotation cell/camera |
| `/api/digiflot/stages/start` | POST | Start first or next stage |
| `/api/digiflot/stages/finish-now` | POST | Finish currently active stage |
| `/api/digiflot/stages/skip` | POST | Skip stage with reason |
| `/api/digiflot/stages/acquisition/override` | POST | Override upcoming stage recording flags |
| `/api/digiflot/stages/measurements/ignore` | POST | Audit waiver and advance when required measurements are missing |
| `/api/digiflot/pause`, `/resume`, `/abort` | POST | Run control |
| `/api/digiflot/recovery/retry-devices` | POST | Retry devices without changing current stage |
| `/api/digiflot/recovery/resume` | POST | Resume from recovery |
| `/api/digiflot/recovery/restart-stage` | POST | Retry stage; old attempt remains recorded |
| `/api/digiflot/storage/estimate` | POST | Storage requirement/autonomy estimate |

For an upcoming stage's recording override (the `enabled` keys must match configured channels):

```json
{"enabled":{"video/0":false,"video/all":false,"atlas":true,
            "virtual/froth_interface":true}}
```

A missing required measurement yields a rejected `/stages/start` operation. To explicitly ignore the gate and advance:

```json
{"reason":"Sampling was not available; operator acknowledged missing results"}
```

Use this endpoint only while the controller is **Running / Transition** with outstanding required variables. It is an auditable exception, not a generic skip endpoint.

## Measurements and inputs

| Endpoint | Method | Purpose |
| --- | --- | --- |
| `/api/digiflot/measurements` | GET | Captured observations and variable summaries |
| `/api/digiflot/measurements` | POST | Capture manual value or a sensor snapshot |
| `/api/digiflot/execution-inputs/cell-profile` | POST | Save execution-specific cell profile |

Representative manual numeric observation:

```json
{"variable_id":"pulp_density","variable_name":"Pulp density",
 "source_id":"manual","value":1200,"unit":"g/L",
 "value_type":"number","role":"measurement","category":"measurement"}
```

For sensor capture, set `source_id` to a configured sensor and omit `value`; the Edge captures the sensor's current numeric snapshot. Typed text observations require manual source and `value_type:"text"`. A live reading alone is not a persisted measurement. Records include time, stage and attempt context.

## Physical sensors, cameras, results

- `/api/cameras`, `/api/cameras/{camera_id}`: camera inventory and configuration. Preview routes include `/{camera_id}/preview/start`, `/preview/heartbeat`, `/preview/stop`; streams use `/{camera_id}/stream`.
- `/api/sensors`, `/api/sensors/stream`, `/api/sensors/{sensor_id}`, `/{sensor_id}/stream`: configured sensors and streaming values.
- `/api/results/*` and Results pages: stored measurements and images/video metadata. Media playback is isolated from active runs, on-demand over WebSocket.
- `/api/digiflot/performance*`, `/api/digiflot/scraping/alerts`, `/api/digiflot/settings`: performance, scraping alerts and operating settings.

## Errors and state guards

The Run UI and API use a controller state machine. Expect 409 Conflict when an operation is incompatible with the active state or camera ownership; 422 for invalid values; 404 for a missing local record. Treat a rejected command as **not applied**. Never assume a calibration, measurement or transition succeeded until the response is received and the state reflects it. Check `/api/digiflot/state` after a network interruption.

See [Stages and measurements](EXPERIMENTS_STAGES_MEASUREMENTS.md) for semantics and [Troubleshooting](TROUBLESHOOTING.md) for recovery.
